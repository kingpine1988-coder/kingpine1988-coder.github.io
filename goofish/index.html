闲鱼智能监控 · 打开面板

打开可交互的监控面板

本页是静态展示页，按钮点不动。真正的监控面板跑在你自己电脑上，通过 Cloudflare 隧道暴露成公网地址。

怎么拿地址？双击桌面 闲鱼监控_公网访问.bat，黑色窗口里会出现一行 https://xxxx-xxxx.trycloudflare.com，复制粘到上面即可。
免费隧道地址每次重启都会变，重新打开后把新地址贴进来就行；本页会自动记住你上次填的地址。
它能做什么
👀

AI 看图分析

把商品截图交给视觉大模型，自动判断成色、型号、瑕疵，不再只靠关键词碰运气。

🎯

大白话建任务

用自然语言描述你要找什么、预算多少、排除什么，零基础也能配置监控规则。

📢

多渠道推送

命中好物后通过微信、Telegram、Bark、ntfy、Webhook 等渠道即时通知你。

🔐

本地登录态

监控跑在你自己的电脑和浏览器环境，保留闲鱼登录 Cookie，风控更低。

三步开始使用
1

启动服务

双击桌面 闲鱼监控_公网访问.bat，保持黑窗口开着。

2

拿到地址

复制窗口里打印的 https://xxx.trycloudflare.com，贴到本页上方。

3

登录配置

用账号 admin 登录，在「账号管理」导出闲鱼登录态，再「任务管理」建任务。

说明：这些页面部署在 GitHub Pages，只能提供静态内容；闲鱼监控需要 Python 后端 + 浏览器爬虫 + 定时任务，无法在 Pages 上运行。 程序本体运行在你自己的电脑上，本页只是它的门面。想让公网地址固定不变，可进一步配置 Cloudflare Named Tunnel（需自有域名）。
